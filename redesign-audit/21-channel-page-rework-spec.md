# 通道管理页改版:分类列表 + 统一新增/编辑浮窗 Spec

- 分支:`feature/bailian-provider`(延续)
- 状态:待实现
- 用户拍板:
  - ① 凭证类导入**在浮窗内向导完成**(不做跳转引导);
  - ② 密钥类**放开多 Key 并存**(去掉单活跃约束,调度按权重/优先级轮换);
  - ③ 详情区 = **只读摘要 + 操作按钮**,表单全部进浮窗;
  - ④ 术语保持「登录型/密钥型」。
- 另含两个必修 bug:`< strong` 标签空格;凭证列表挪出详情 card。

## 1. 心智模型(本次改版的依据)

- **登录型 = 硬编码配置模板**:五家平台(workbuddy/qclaw/qwenwork/traework/traesolo)各有专属导入逻辑;新增平台=改代码。一个平台可挂多个凭证(现状已支持)。
- **密钥型 = 通用模板实例**:Base URL + Key + 模型白名单即可新增,零代码;seed(gmi/bailian)与用户自定义同机制。
- 通道列表分组展示这两种模板;凭证列表是全局汇总,与详情平级。

## 2. 页面结构(重排后)

```
「通道管理」
  Card A · 通道列表(分组)
    ├─ 分组头「登录型平台」:五个固定平台(行点击=选中)
    ├─ 分组头「密钥型通道」 + 组头右侧「新增」按钮:seed + 用户自定义
    └─ 每行:显示名/ID/徽标(builtin/apikey、custom/seed)/启用开关
  Card B · 详情(只读摘要 + 操作按钮)
    ├─ 登录型:平台说明(登录目录/导入方式一句)+ 启用状态
    ├─ 密钥型:Base URL/模型白名单/别名/env/来源 摘要
    │   按钮:编辑(浮窗)/ 删除(非 seed)/ 停用走列表开关
    └─ `< strong` bug 修复(标题正确渲染)
  Card C · 凭证区(选中通道的导入/粘贴面板)
    ├─ 登录型:本机检测/自定义路径/SOLO 网页登录(现有逻辑,挂在选中通道)
    └─ 密钥型:提示"密钥在浮窗中添加/轮换",或保留快捷粘贴(见 §4.4)
  Card D · 凭证列表(独立,全量汇总,通道筛选下拉)
    └─ 现 accounts 表格整体迁出详情,放页面底部;多 Key 并存后行数可见
```

## 3. 后端改动(仅一处,配合多 Key)

`src/providers/openai_compat.py` 基类 `upsert_account`:**删除"把其它 active 行置 inactive"的单活跃约束**(gmi/store.py 复制来的遗留)。同 uid 覆盖更新的语义保留;不同 uid 的 Key 各自成行,全部 active,`pick_account` 按既有权重/优先级轮换(auth_manager 无需改)。补充:
- `store_common`/文档口径同步(若注释提到"单 key 平台"改写);
- tests/test_custom_channels_gmi.py 等处的"单 active 行约束"断言改为"多行并存"断言(测试即规格,本次是规格变更点,需在报告中注明)。

其余后端零改动(浮窗用现有 GET/POST/PUT/DELETE /admin/channels/custom 契约)。

## 4. 前端(channels.js 改造)

### 4.1 Card A 分组列表
- `list` 按 `kind` 分两组渲染;登录型组头固定五平台(不加新增);密钥型组头右侧「新增」按钮 → 打开浮窗(mode=create,类型预选密钥型);
- 行为、开关逻辑不变;`< strong` → `<strong` 修复在详情标题处一并做。

### 4.2 统一浮窗(核心新增)
一个 modal,两步:
1. **选类型**(仅 create 时出现):「登录型平台」/「密钥型通道」两个大按钮;
2. **登录型向导**(选平台后):
   - 平台下拉(五家)→ 按平台展示对应导入步骤(从 Card C 现有逻辑复用/搬移):
     - workbuddy/qclaw/qwenwork/traework:本机检测说明 + 「检测」按钮 + 结果文件表 + 「导入」(调 discover/import);
     - traesolo:「发起网页登录」+ 回调粘贴「手动完成」(solo 状态机);
   - 完成 → toast + 刷新凭证列表 + 关闭浮窗;
3. **密钥型表单**(create/edit 共用,字段=现 ccForm):ID(edit 禁改)/显示名/Base URL/模型白名单/别名/env/API Key(编辑留空=不轮换);保存调 POST/PUT /admin/channels/custom,探活 warning 展示不变;
- 编辑入口:Card B「编辑」按钮(密钥型)→ 浮窗 edit 模式;登录型无"编辑定义"概念(内置),只读。

### 4.3 Card B 只读摘要
- 删除现内嵌编辑表单(ccForm 编辑分支移除);保留摘要展示;密钥型加「编辑」按钮;`< strong` 修复。

### 4.4 Card C 凭证区(选中通道上下文)
- 登录型:保留现有导入 UI(检测/路径/SOLO)——浮窗向导与这里是**同一份逻辑的复用**(实现时抽成可复用的函数/模板片段,两处都调它,不复制两份);
- 密钥型:改为轻提示 +「添加/轮换密钥」按钮(开浮窗直抵密钥表单);原 keyKey 粘贴面板移除(入浮窗),避免两处编辑入口。

### 4.5 Card D 凭证列表
- 现表格整体挪出详情 card,页面底部独立 card;筛选/操作列/「高级手动添加」不变;通道筛选下拉已存在,多 Key 行自然展示。
